About Roamie 🗺️

Roamie is a custom-built Natural Language Local Place Finder Midterm-Finals project designed to help users explore local venues in Ilocos Norte!

  • 🚫 No External AI APIs (0% dependencies on OpenAI, Gemini, or Claude)
  • ⚡ No Pre-made ML Classifiers or heavy machine learning models
  • 🔍 Pure Rule-Based NLP Architecture using custom TF-IDF lexical matching, regular expressions, and gazetteer-based entity extraction.
